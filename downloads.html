Cost and credential controls

The retained resource types can continue charging: compute, disks, Bastion, NAT, monitoring and applicable Azure Local services. Alerts are not a hard spending cap. A tag such as CostControl=Ignore is an explicitly authorized internal-lab exception, not a general Azure requirement or a security control. The guide does not publish actual subscription billing data.

The demonstration lab used a shared administrator password across some Windows targets. Do not reproduce shared administrator credentials in production; use separate, least-privilege, managed administrative identities. Azure portal identity, Windows local/domain sign-in and Ubuntu SSH authentication are different trust boundaries.

What is not claimed

  • The nested lab is not a production topology or an independent physical failure domain.
  • Examples are version-sensitive. Discover supported Kubernetes versions and VM sizes rather than assuming an old version remains available.
  • A menu screenshot is not a completed-migration result; one-second browser polling cannot prove absolute zero downtime.
  • The existing guide repository and its Pages homepage are not changed by this separate site's publication.
